// recovery

Open a backup without SeedLock

Your backups do not depend on this program. If SeedLock ever disappears, a separate, short Python program can still give you back your seed words.

recover.pyFORMAT.mdUser guide
// what you need

What you need

  • Your backup file (.seedlock) and its password.
  • An offline computer with Python 3. Like SeedLock, the program shows your words, so run it only on an offline computer.
  • recover.py, in the tools folder of SeedLock’s download.
// steps

Steps, for your system

First copy recover.py to the offline computer, into the folder that holds seedlocker backups (SeedLock’s folder). Then open the box for your system. Each one has two parts: install the three Python libraries it needs while the computer is online, then run it offline.

Linux: Debian and Ubuntu

Recent Debian and Ubuntu systems do not let pip change the system’s Python, so you make a separate one in the folder.

1. While the computer is still online, in a terminal in that folder:

sudo apt install python3 python3-venv python3 -m venv recover-env recover-env/bin/pip install argon2-cffi pynacl mnemonic

2. Disconnect the computer, then type:

recover-env/bin/python3 recover.py "seedlocker backups/my wallet.seedlock"

It asks for the password and prints the words.

Optional: check that the program itself works, with a known test:

recover-env/bin/python3 recover.py --selftest
Linux: Arch

Arch also protects its system Python, so use a separate one in the folder here too.

1. While the computer is still online, in a terminal in that folder:

sudo pacman -S python python -m venv recover-env recover-env/bin/pip install argon2-cffi pynacl mnemonic

2. Disconnect the computer, then type:

recover-env/bin/python recover.py "seedlocker backups/my wallet.seedlock"

It asks for the password and prints the words.

Optional: check that the program itself works, with a known test:

recover-env/bin/python recover.py --selftest
macOS

Open Terminal. Type python3 --version. If Python 3 is missing, macOS offers to install it with the Command Line Tools, or you can install it from python.org.

1. While the computer is still online, in a terminal in that folder:

python3 -m venv recover-env recover-env/bin/pip install argon2-cffi pynacl mnemonic

2. Disconnect the computer, then type:

recover-env/bin/python3 recover.py "seedlocker backups/my wallet.seedlock"

It asks for the password and prints the words.

Optional: check that the program itself works, with a known test:

recover-env/bin/python3 recover.py --selftest
Windows

Install Python 3 from python.org while the computer is still online, and keep the py launcher option ticked. Then open PowerShell in the folder: in File Explorer, open the folder, click the address bar, type powershell and press Enter.

1. While the computer is still online:

py -m pip install argon2-cffi pynacl mnemonic

2. Disconnect the computer, then type:

py recover.py "seedlocker backups\my wallet.seedlock"

It asks for the password and prints the words.

Optional: check that the program itself works, with a known test:

py recover.py --selftest

Important: disconnect the computer before you run the program. Like SeedLock, it shows your seed words on the screen.

// no python

Any language works

Python is not needed. The backup format is documented byte for byte in FORMAT.md, so you can write your own reader in any language, even in ten years.

It only needs four standard parts: SHA-256, Base32, Argon2id, and XChaCha20-Poly1305 (in libsodium, crypto_aead_xchacha20poly1305_ietf).

  • A backup is 100 bytes: a header with the Argon2id settings, a salt, a nonce, and the encrypted words.
  • The key comes from your password, normalised as NFKD, with Argon2id.
  • The words are the standard BIP39 English list.

FORMAT.md also has a test vector, so you can check that your own reader is right.

// good to know

Good to know

  • A wrong password and a damaged file look exactly the same. This is by design.
  • The BIP39 passphrase (the “25th word”) is never stored in a backup. Keep it safe yourself.
  • A reader that sees a format version it does not know must stop, and never guess.
