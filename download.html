Check your download

Each release has a list of fingerprints, SHA256SUMS.txt, and its signature. Compare your file’s SHA-256 number with the list before you copy the program to the offline computer. The list is signed with SeedLock’s release key:

E435 21D9 44AE 9BAA 9FB2 D11D 08B6 5FB6 5CB1 D806

How to check

  1. Compute the SHA-256 fingerprint of the file you downloaded (commands below).
  2. Compare it with the line for that file in SHA256SUMS.txt. The two numbers must be exactly the same.
  3. Safer still, check the signature of SHA256SUMS.txt. Download SHA256SUMS.txt.asc from the same release and release-key.asc from the docs folder on GitHub. It must say Good signature, and the primary key fingerprint must be the one above. The User guide explains it step by step.

Command line

# Linux sha256sum seedlock-<version>-linux-x86_64 # macOS shasum -a 256 seedlock-<version>-macos # Windows (PowerShell) (Get-FileHash seedlock-<version>-windows-x86_64.exe).Hash # Android apk (on the computer you downloaded it to, Linux) sha256sum seedlock-<version>-android.apk # Signature of SHA256SUMS.txt (all systems, needs GnuPG) gpg --import release-key.asc gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt

Not independently audited: try it on testnet, or with a small amount, first.
